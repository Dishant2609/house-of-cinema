# 🎬 House of Cinema

A cinematic movie & TV discovery app built with React, Vite, and TMDB API.

## Features

- 🎥 Trending movies, top rated, now playing, upcoming
- 📺 TV Shows — trending, crime, psychological, international
- 🎌 Anime section
- 🔍 Search movies and shows
- 🎭 Mood-based movie quiz
- 🎬 Director profiles & filmographies
- ❤️ Watchlist (saved locally)
- 🖼️ Movie detail modal with trailers, cast, streaming platforms

## Tech Stack

- **Frontend** — React 19, Vite, TailwindCSS, TanStack Query
- **Routing** — Wouter
- **API** — TMDB (via edge function proxy)
- **Deployment** — Vercel
